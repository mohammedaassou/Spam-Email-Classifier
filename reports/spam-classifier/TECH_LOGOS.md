# Technology logo sources

The five logos in `assets/` come from official project websites or official project repositories. They are stored as PNG files so the report compiles with Tectonic without image conversion during the build.

| Technology | Local file | Official source |
|---|---|---|
| Python | `logo_python.png` | [Python Software Foundation logo page](https://www.python.org/community/logos/) |
| pandas | `logo_pandas.png` | [pandas citation and logo page](https://pandas.pydata.org/about/citing.html) |
| scikit-learn | `logo_scikit_learn.png` | [scikit-learn branding page](https://scikit-learn.org/dev/about.html#branding-logos) |
| FastAPI | `logo_fastapi.png` | [FastAPI official website](https://fastapi.tiangolo.com/) |
| Matplotlib | `logo_matplotlib.png` | [Official Matplotlib Sphinx theme repository](https://github.com/matplotlib/mpl-sphinx-theme) |

The pandas and Matplotlib source files were SVGs. They were converted once to PNG before being added to this report; the LaTeX build reads only the PNG copies.
