# Spam Email Classifier report

Build from this directory with Tectonic:

```sh
tectonic -X compile main.tex
```

The project uses standard LaTeX packages and local PNG assets. It does not require shell escape, image conversion, or a separate bibliography processor. Tectonic may download standard packages on its first run if they are not cached.

The report's `assets/` directory contains 12 figures and five official technology logos. Ten figures are copies from the repository's `artifacts/` directory; two validation charts were redrawn from the saved counts with reader-friendly labels. The metrics study sketch is excluded at the author's request. See `IMAGE_COVERAGE.md` for the figure mapping and `TECH_LOGOS.md` for the logo sources. The original assets and the old report under `docs/sections/` are unchanged.
